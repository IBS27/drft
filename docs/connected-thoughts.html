drft · design proposal
Related thoughts · web + iOS

Let the words take the width.

Replace the current horizontal string of clipped labels with one quiet, left-aligned list below the thought. The thought remains the center of gravity. Related thoughts become readable destinations rather than tags, and when there are none, the section leaves no trace.

01

Verbatim, not compressed

Sentence case, natural wrapping, and the full thought. No uppercase transformation or character cap.

02

Near, not competing

A wide field of space separates the primary thought from a smaller, quieter reading list.

03

Absent means absent

No empty-state copy, count, divider, or reserved gap when a thought has no related thoughts.

Recommended direction

A shared list language

Same hierarchy on both platforms; only density and native interaction change. Use the controls to see dark mode and the truly empty state.

Text

Related thoughts use sentence case at a body size. They wrap for as many lines as needed; nothing is ellipsized.

Hierarchy

The main thought stays centered and light. The list is left-aligned, smaller, and begins after 46–54px of air.

Open

The whole row is a destination. Web gets a quiet hover state; iOS gets the native pressed state and push transition.

Set aside

Web reveals × on hover or focus. iOS uses a trailing swipe action. Both keep the existing eight-second undo.

Why this is the right fit

The list fixes the readability problem without turning related thoughts into a new product surface. There are no cards, scores, summaries, or AI explanations—just a small heading and the user’s own words. On iOS it extends the existing thought screen cleanly: the API model already carries the relationship data, so the new surface can share the web’s navigation and set-aside behavior while staying native in gesture and spacing.
