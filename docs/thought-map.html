01 · literal

The constellation

The closest reading of an Obsidian-style graph: every connection is always present, node size follows the number of links, and selecting a point opens the thought in a fixed margin. It makes the system legible immediately.

Trade-off: honest and explorable, but larger collections become a hairball. The permanent inspector also makes the room feel more like software than drft.

02 · quiet by default recommended

The quiet field

All thoughts are present, but the web of edges waits for intent. Points sit like dust in the room; hover or keyboard focus reveals one thought, its words, and only its direct resonances. Clicking opens the existing thought page.

Why it fits: the whole collection is perceptible without becoming a diagram to decode. It preserves Stillness, scales better, and lets the accent keep its current meaning: the vermilion point is where attention is now.

03 · guided

The thread lens

The complete graph stays in the periphery while one local neighborhood is magnified into a calm reading circle. Direct links sit close; the next hop marks possible paths outward. It turns the graph into a way of wandering rather than surveying.

Trade-off: the most readable concept, but it weakens the feeling of seeing the whole collection at once. The lens is also a new interaction model that must be learned.

Start with quiet, keep the graph honest.

Use the connection table

Edges should be the same user-dismissable resonance links already visible on thought pages. Do not invent cluster names or expose similarity scores.

Ship the quiet field

It satisfies “all thoughts” while postponing density until the user points somewhere. The default frame feels like drft; interaction reveals the graph.

Keep it at the desk

Add connections directly above settings in the desktop rail. No compact fallback and no iOS version: deliberate wandering belongs to the web workspace.
